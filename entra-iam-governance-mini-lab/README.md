# Entra ID / IAM Governance Mini Lab

This mini lab demonstrates practical identity and access governance thinking for Microsoft-oriented environments.

It is designed as a recruiter-friendly proof of work for roles involving IAM, Identity Provider operations, Entra ID, access governance, lifecycle processes, documentation and security automation.

## Purpose

The goal is to show how identity governance can be documented and structured as both a technical and organisational process.

## What this lab includes

- Identity lifecycle model
- RBAC role matrix example
- Conditional access baseline
- SSO and MFA concept notes
- Access review checklist
- Audit logging requirements
- PowerShell-style pseudocode for access review reporting

## Relevant skills demonstrated

- Identity lifecycle thinking
- Access governance documentation
- Role-based access design
- Approval and review workflows
- Microsoft Entra ID concepts
- Auditability and evidence handling
- Communication between security, HR, support and application owners
