# Access Review Checklist

This checklist supports periodic review of access rights for users, privileged roles and application access.

## Review scope

- Business users
- Privileged users
- Application owners
- External consultants
- Service accounts
- Emergency access accounts

## Checklist

| Question | Evidence |
|---|---|
| Is the user still active in the organisation? | HR status or manager confirmation |
| Does the user still need the access? | Role description or business justification |
| Is the access aligned with the user's current role? | Role matrix comparison |
| Is privileged access limited and approved? | Approval record and privileged account list |
| Are exceptions documented? | Exception register |
| Are inactive accounts removed or disabled? | Deactivation record |
| Are application owners involved in the review? | Review sign-off |

## Review outcome categories

- Keep access
- Modify access
- Remove access
- Escalate for owner decision
- Time-limit and review again

## Good review practice

- Use clear ownership.
- Keep evidence of decisions.
- Avoid permanent exceptions.
- Separate user accounts from service accounts.
- Review privileged access more often than standard access.
