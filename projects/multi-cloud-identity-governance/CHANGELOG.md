# Changelog

## 0.1.0 — 2026-11-26

- Added a deterministic workforce lifecycle planner and in-memory executor for joiner, mover, leaver, contractor-expiry and access-review cases.
- Added Azure, AWS and GCP export normalizers, catalogue coverage checks and source provenance.
- Added plan-bound synthetic approvals, expiry checks, separation-of-duties rules and grant freeze after a failed removal.
- Added before/after reports, control findings, an audit hash chain and local manifest verification.
- Added acceptance, provider, import, adversarial and evidence tests, with a repeatable demonstration.
- Documented the business scenario, cloud hosting design, control mapping, threat model, interview walkthrough and community benchmark.

This release has no live cloud collector, cloud executor or tenant validation.
