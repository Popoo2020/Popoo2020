# Release Notes: v0.1.0

## ISO42001-AI-Governance-Evidence-Toolkit

Initial portfolio release of the AI Governance Evidence Toolkit.

## Highlights

- AI use-case register sample
- AI risk register sample
- ISO/IEC 42001-oriented governance control mapping
- Human oversight decision log
- Draft internal AI-use policy
- AI impact assessment example for SME/e-commerce AI workflows
- AI supplier due-diligence checklist
- EU AI Act risk-classification readiness note
- AI incident and complaint handling template
- Client-facing AI governance readiness consulting offer
- Sundai AI-style client case study
- Python readiness report generator
- Sample readiness report
- Unit tests for report generation utilities
- CI workflow for tests and report generation
- Dependabot and CodeQL configuration in the profile repository

## Positioning

This release is intended as a portfolio-grade readiness toolkit for AI Governance, Cybersecurity GRC, ISO/IEC 42001 readiness and SME consulting demonstrations.

It is not legal advice, certification evidence or a full ISO/IEC 42001 implementation package.
