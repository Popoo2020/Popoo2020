# IT/OT Governance Mini Lab

This mini lab demonstrates practical governance thinking for organisations operating across IT and industrial technology environments.

It is designed as a recruiter-friendly proof of work for roles involving IT/OT security governance, compliance documentation, risk tracking, evidence handling and control mapping.

## Purpose

The goal is not to claim deep industrial engineering experience. The goal is to show how I structure security documentation, translate standards into working artifacts and create repeatable governance material for regulated technical environments.
